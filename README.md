Create ENV 
- python -m venv thesis-env
- source thesis-env/bin/activate      # macOS / Linux
- thesis-env\Scripts\activate         # Windows

Installing Dependecies
- python -m pip install numpy scikit-learn matplotlib jupyter or
- pip install numpy scikit-learn matplotlib jupyter
- Also install jupyter vscvode extension

Starting jupyter
- python -m notebook or 
- jupyter notebook
